# Cómo pasar el informe a Google Docs

1. **Opción 1 (la más fácil).** Sube Builder_Case_para_Docs.docx a Google Drive y ábrelo con Google Docs (clic derecho, Abrir con, Documentos de Google). Conserva Arial, las tablas y el texto en negro.

2. **Opción 2.** En un documento nuevo de Docs, activa Herramientas > Preferencias > Habilitar Markdown. Copia todo Builder_Case_para_Docs.md y pégalo con Editar > Pegar desde Markdown. **Opción 3.** Si nada de lo anterior funciona, pega Builder_Case_para_Docs.txt (las tablas quedan como texto separado por barras).

3. **Fuente.** Selecciona todo (Ctrl o Cmd + A) y pon Arial. Revisa que el texto sea tamaño 11 e interlineado 1,15, con márgenes de 1 pulgada en tamaño carta.

4. **Quitar enlaces automáticos.** Si alguna URL de las referencias queda azul o subrayada, haz clic en ella, presiona Ctrl o Cmd + K y elige Quitar. Para que no vuelva a pasar, desmarca Herramientas > Preferencias > Detectar vínculos automáticamente.

5. **Exportar.** Archivo > Descargar > Documento PDF, con el nombre exacto MAKERS_SANTIAGO_ESPINOSA_CALI.pdf. Antes de enviarlo, abre el PDF y confirma que el cuerpo termina en la página 5 y que ANEXOS empieza en la página 6.
